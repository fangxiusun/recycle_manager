  - [ ] `docs/` 三份中文详解的英文版
  - [ ] **增量读 `$I` 的缓存**：`$I` 内容一旦写下就不再改，而整盘列目录只要 7~16ms（本机 13 888 个目录项，
        2026-10-21 那一轮），所以「只读新增/改动的 `$I`、其余复用上一次快照」能把全量扫描压到列目录的量级。
        代价是要一份按 `$I` 文件名记的缓存与失效规则，还得保证缓存和真实回收站不会各说各话。
  - [ ] 并行读 `$I`（**实测过，判定为不划算，除非做了上一条之后再回头看**）：同一批 6 936 个文件在临时目录里
        扫 worker 数，1/2/4/8/16 两轮是 558→337ms 与 655→304ms，**4 worker 就到顶（约 1.7×）**，
        8 不再涨、16 回弹。要付的代价是并发度靠猜文件数、且挤占其它进程的 IO，所以没做进主干。
  - [ ] 网络盘上的回收站默认不进扫描（`--drives y` 才看）：换掉的是「一个失联盘拖死整次扫描」，
        如果有人就是要靠自动枚举扫到映射盘，需要一个新的口径（比如只探测、超时就让开）。
  - [ ] 代码签名：未签名产物首次运行会被 SmartScreen 拦一次
